# Typenet

> A type-safe, batch-buffered networking library for Roblox, built with roblox-ts.

---

## ⚠️ Undergoing Full Rewrite

Typenet is being rewritten from scratch. The current codebase is not production-ready and the existing API is being scrapped entirely.

**Do not use the current version for anything.** There will be no migration path from v1.

The rewrite will be announced here when it reaches a usable state.
